# pstack 中文课程

这是一门讲 pstack 的中文课。pstack 是 Lauren Tan（X：[@poteto](https://x.com/poteto)）开源的一套 agent 技能、playbook 和工程原则，入口只有一个 `/poteto-mode`。

上一版只是一张链接表。这一版每章都写了我的分析：它解决什么问题，机制怎么运转（引用源码原文），为什么这样设计，代价和失败模式，社区怎么用，以及 [calvingit/skills](https://github.com/calvingit/skills) 能借鉴什么。

```callout tip 怎么读
第一次按顺序读 0 到 7 章。第 8、9 章是进阶，第 10 章是社区资料，第 11 章专门对照我们自己的仓库。每章末尾有练习，可以勾选，进度存在你的浏览器里。
```

版本基准：pstack **0.15.23**（2026-10-14）。时间都是北京时间。标 【已核实】 的是我读过原文；标 【未核实】 的是只看到摘要、转述或作者自述数字。
